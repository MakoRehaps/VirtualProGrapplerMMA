# Base stance system

Stance is gameplay data, not just animation selection.

A stance controls the fighter's default:
- lead side and facing
- posture and guard
- foot orientation, width and depth
- front/rear weight distribution
- forward/back/lateral/pivot/burst movement bias
- readiness for punches, kicks, clinch, takedowns, sprawls, throws and ground entries
- preferred ranges

Styles reference a reusable base stance. Individual fighters may later override lead side, stance width, posture, or use alternate stances.

Stances are intentionally broader than styles: many styles can share a physical stance archetype while still having completely different technique libraries and combat logic.
